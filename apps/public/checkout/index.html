결제 전 확인해야 할 사항

리포트는 어디에서 확인하나요?

결제 후 리포트 생성 상태와 결과물은 고객 포털에서 확인합니다. 이메일은 주문 확인과 고객지원 연락에 사용됩니다.

환불 기준은 어떻게 확인하나요?

리포트 생성 전, 생성 후, 전문가 검토 시작 전후 기준이 다릅니다. 결제 전 환불 정책을 확인해 주세요.

결제 실패나 생성 오류가 발생하면 어떻게 하나요?

결제는 되었지만 리포트 생성이 실패하면 고객지원에서 재생성 또는 환불 가능 여부를 안내합니다.

법률 자문인가요?

아닙니다. 공개 웹페이지 기준의 실무 체크리스트와 보완 후보를 제공하며, 법률 판단은 별도 전문가 검토가 필요합니다.
