결제 전 확인해야 할 사항

결과물은 어디에서 확인하나요?

결제 후 주문 상태와 결과물은 고객 포털에서 확인합니다. 이메일은 주문 확인, 결제 안내, 고객지원 연락에 사용됩니다.

월간 상품은 자동으로 다음 달에도 결제되나요?

아닙니다. 현재 월간 모니터링과 전문가 플랜은 수동 갱신형입니다. 다음 이용 기간은 별도 재결제 또는 갱신 요청이 있을 때만 시작됩니다.

환불 기준은 어떻게 확인하나요?

1회성 디지털 산출물은 생성 전후, 월간 상품은 당월 이용 시작 전후 기준이 다릅니다. 결제 전 환불 정책을 확인해 주세요.

결제 실패나 생성 오류가 발생하면 어떻게 하나요?

결제는 되었지만 산출물 생성 또는 서비스 개시가 정상적으로 이뤄지지 않으면 고객지원에서 재생성, 재처리, 환불 가능 여부를 안내합니다.

법률 자문인가요?

아닙니다. 공개 웹페이지 기준의 실무 체크리스트와 보완 후보를 제공하며, 최종 법률 판단은 별도 전문가 검토가 필요합니다.
