회원 계정에서 할 수 있는 일

  • 결제 후 리포트, 수정안, 템플릿 확인
  • 주문 이력과 사이트별 진단 이력 확인
  • 회원가입 때 이름, 회사명, 전화번호, 주소를 요구하지 않음
  • 내 사이트 관리에서 구독 상태와 맞춤 안내 확인
  • 주문 접근 토큰과 로그인 세션으로 산출물 접근 보호
