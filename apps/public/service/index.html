중요

무료 진단

공개 페이지를 기준으로 확인이 필요한 영역과 점검 요소를 보여드립니다.

기본 리포트

발견 항목의 위치, 원인, 우선순위, 수정 방향을 확인할 수 있습니다.

전문가 리포트

수정 문구안, 적용 순서, 재점검 기준까지 실행 가능한 형태로 제공합니다.

점검하는 항목

  • 사업자 정보, 고객센터, 연락 가능 경로 표시 여부
  • 가격, 결제 전 안내, 제공 범위, 추가 비용 고지 여부
  • 환불·청약철회·취소 기준의 명확성
  • 개인정보 수집·이용 안내와 동의 흐름
  • 후기, 할인, 혜택, 보장 표현의 오인 가능성
법률 자문이 아닙니다

VERIDION의 자동 진단은 공개 페이지 기준 참고용 점검입니다. 실제 확인 필요 여부, 법적 판단 여부, 분쟁 결과는 사실관계와 관할기관 판단에 따라 달라질 수 있습니다.
