정책 문서와 작업지시서를
바로 실행 가능한 초안으로 정리합니다

개인정보처리방침, 환불 정책, 이용약관 같은 운영 참고용 초안과 내부 실행용 작업지시서를 한 화면에서 정리합니다. 입력 → 생성 → 복사/저장 흐름으로 단순하게 사용합니다.

문서 초안 만들기 사이트 진단

생성 흐름

3단계
1. 요청 입력작업 목표, 금지 조건, 검수 요구를 그대로 붙여넣습니다.
2. 지시서 생성실행 작업, 완료 기준, 검수 방법, 보완 기준으로 정리합니다.
3. 복사·저장결과를 복사하거나 브라우저에 임시 저장해 바로 전달합니다.

출력 원칙

일관 구조
문서 초안 1개결과는 하나의 최종 작업지시서 또는 정책 문서 초안으로 정리됩니다.
검수 가능각 작업에 완료 기준과 검수 방법을 포함합니다.
확인 필요 분리확정할 수 없는 정보는 별도 항목으로 분리합니다.

요청 입력

정책 문서, 고객 안내문, 내부 작업 요청을 필요한 만큼 붙여넣으세요.

생성
요청문을 입력한 뒤 생성 버튼을 눌러주세요. 정책 문서 초안과 작업지시서 생성 흐름을 함께 지원합니다.

검수 기준

QA
필수 포함

정책 문서 초안은 확인 필요 정보를 분리하고, 작업지시서는 실행 작업·완료 기준·검수 방법·롤백/보완 기준을 포함해야 합니다.

출력 차단

요청하지 않은 형식, 확정할 수 없는 사실, 불필요한 설명은 최종 결과에서 제외합니다.
