결제 전 안내를 고칠 때 보는 실무 체크리스트

사업자 정보, 개인정보처리방침, 환불 정책, 약관, 광고 문구를 실제 화면에 어떻게 배치할지 기준을 정리했습니다.

무료 진단 시작
1푸터 고지상호·대표자·사업자번호·통신판매 고지
2개인정보수집 항목·목적·보관 기간·동의 위치
3환불 기준가능 조건·제한 사유·처리 기간
4광고 표현확정형 문구를 완화 표현으로 수정

1. 푸터 고지

고객이 회사 실체를 확인하는 기본 영역입니다. 푸터에는 상호, 대표자 또는 책임자, 사업자등록번호, 고객지원 연락처, 통신판매 관련 고지를 한곳에 모아 둡니다.

  • 모바일 하단에서도 접히지 않게 배치
  • 사업자 정보 확인 링크와 함께 노출
  • 고객지원 이메일 또는 문의 경로 명확화

2. 개인정보 안내

입력창과 동의 문구가 멀면 고객은 불안해합니다. 회원가입, 문의, 결제 화면 가까이에 수집 목적과 처리방침 링크를 둡니다.

  • 수집 항목과 목적을 한 줄로 요약
  • 보관 기간 또는 파기 기준 안내
  • 선택 항목은 선택이라고 분리

3. 환불·교환 기준

환불 가능 조건, 제한 사유, 처리 기간을 섞지 말고 분리해야 합니다. 디지털 산출물은 제공 시작 이후 제한 가능성을 결제 전 고지합니다.

  • 제공 전/후 기준 분리
  • 처리 기간과 문의 경로 표시
  • 예외 조건은 짧고 명확하게 작성

4. 광고 문구

“무조건”, “100%”, “완전 해결” 같은 확정 표현은 증빙이 없으면 위험합니다. 가능한 범위와 조건을 함께 쓰는 문장으로 바꿉니다.

  • 확정형 → 조건부·가능성 표현
  • 수치 표현은 근거와 기간 표시
  • 혜택 문구는 제한 조건 근처에 배치
