내 사이트

한 번 저장하고 진단·주문·산출물을 이어서 봅니다.

사이트 주소를 저장하면 재진단, 상품 비교, 주문 이력, 리포트와 수정안을 같은 기준으로 관리할 수 있습니다.

새로 진단하기
1사이트 저장자사몰·랜딩·캠페인별 분리
2재진단수정 후 같은 기준으로 확인
3주문 연결필요한 상품만 신청
4산출물리포트·문구안·템플릿 확인

사이트 저장

주소를 저장하면 다음 진단, 결제, 산출물 확인 때 다시 입력하지 않아도 됩니다.

로그인·회원가입
로그인하면 사이트를 저장할 수 있습니다. 비회원 진단 결과도 로그인 후 이어서 관리할 수 있습니다.
