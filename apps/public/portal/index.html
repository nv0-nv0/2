내 사이트 관리

로그인한 회원은 사이트 주소를 저장하고, 같은 사이트 기준으로 재진단·상품 비교·주문·산출물 확인을 이어서 사용할 수 있습니다.

새 진단 실행
1. 사이트 저장

자주 점검할 사이트를 이름과 메모로 구분합니다.

2. 재진단

저장된 주소로 무료 진단을 다시 실행합니다.

3. 결제·산출물

주문 이력과 리포트·수정안·템플릿을 한곳에서 확인합니다.

사이트 저장

한 번 저장하면 다음 진단·결제·리포트 확인 때 주소를 다시 찾지 않아도 됩니다.

로그인·회원가입
로그인 후 저장할 수 있습니다. 비회원 진단 결과도 로그인하면 저장해 둘 수 있습니다.
계정 정보를 확인하는 중입니다.
