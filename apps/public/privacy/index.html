1. 처리하는 개인정보

회원 계정에는 이메일, 비밀번호 해시, 동의 시각을 사용합니다. 결제와 산출물 제공에는 이메일, 주문번호, 결제 식별자, 진단 식별자를 사용합니다.

2. 처리 목적

계정 인증, 주문 확인, 디지털 산출물 제공, 고객지원, 보안 안내, 분쟁 대응, 정책상 의무 이행을 위해 사용합니다.

3. 최소수집 원칙

서비스 제공에 필요하지 않은 이름, 전화번호, 주소는 기본적으로 요구하지 않습니다. 문서 생성 화면에 입력한 공개 사업자 정보는 해당 초안 작성에만 사용합니다.

4. 보유 기간과 파기

처리 목적 달성 또는 보유기간 만료 시 파기합니다. 정책상 보관이 필요한 결제·분쟁 대응 기록은 필요한 범위에서 분리 보관합니다.

5. 정보주체 권리

이용자는 개인정보 열람, 정정, 삭제, 처리정지, 동의 철회를 요청할 수 있습니다. 요청은 ct@nv0.kr로 접수합니다.

6. 안전성 확보조치

비밀번호 해시 처리, 접근권한 관리, 세션 만료, 민감정보 마스킹, 보안 헤더 등 안전성 확보조치를 적용합니다.
