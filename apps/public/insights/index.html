환불 정책

쇼핑몰 환불정책 체크리스트

환불·교환·취소 기준은 고객이 결제하기 전에 이해할 수 있어야 합니다. 이 페이지는 디지털 산출물, 상담, 일반 상품 판매자가 공개 화면에서 먼저 점검할 항목을 정리합니다.

  • 무료 진단·유료 리포트·전문가 검토처럼 상품별 제공 시점을 분리해 안내합니다.
  • 리포트 생성 전·후 환불 조건과 기술 오류 시 조치 기준을 구분합니다.
  • 문의 접수 채널, 처리 기간, 필요한 주문 정보를 정책 페이지와 결제 화면에 반복합니다.

개인정보

개인정보처리방침 필수 항목 체크리스트

고객이 이메일, URL, 문의 내용을 입력하기 전에는 어떤 정보를 왜 수집하고 얼마나 보관하는지 확인할 수 있어야 합니다.

  • URL 진단 기록, 이메일, 결제 연락처, 문의 내용을 실제 수집 항목 기준으로 분리합니다.
  • 각 항목의 이용 목적과 보관 기간을 짧은 문장으로 설명합니다.
  • 삭제 요청, 열람 요청, 고객지원 이메일을 정책 하단에 명확히 둡니다.

신뢰 요소

전자상거래 사이트 신뢰 요소 체크리스트

전자상거래 사이트에서 고객은 상품보다 먼저 “이 사업자를 믿고 결제해도 되는지”를 확인합니다.

  • 푸터와 사업자 정보 페이지의 회사 정보가 일치하는지 확인합니다.
  • 고객지원 이메일과 처리 기준을 정책 페이지와 연결합니다.
  • 환불·개인정보·약관 링크가 모바일에서도 보이는지 점검합니다.

결제 전환

결제 전환율을 낮추는 불안 요소

가격이 매력적이어도 제공 범위, 환불 기준, 문의 경로가 불명확하면 고객은 결제 버튼 앞에서 이탈합니다.

  • 가격 카드에 제공 범위와 제외 범위를 함께 씁니다.
  • 결제 버튼 아래에 환불·문의·제공 시점 요약을 배치합니다.
  • 샘플 리포트 또는 무료 결과 미리보기로 기대치를 맞춥니다.

사업자 정보

사업자 정보 표시 방법

사업자 정보는 고객이 결제 전 신뢰를 판단하는 기본 확인 지점입니다.

  • 푸터에 핵심 사업자 정보를 배치합니다.
  • 별도 사업자 정보 페이지에서 상세 내용을 제공합니다.
  • 정책·환불·문의 페이지와 상호 링크를 만듭니다.
