# PHASE294 Portal Real Layout Fix

## 문제
이전 `/portal` 화면은 전체 폭을 제대로 쓰지 못하고, 카드가 중앙에 작게 몰려 실제 사용이 어려웠습니다.

## 조치
- 대시보드 본문 폭을 `min(100% - 64px, 1440px)` 기준으로 재설정
- 12컬럼 레이아웃으로 카드 재배치
- 상단 카드 3개: 최근 진단 결과 / 빠른 실행 / 다음 행동
- 중단: 새 사이트 등록 폼 전체 폭
- 하단: 내 사이트 현황 / 최신 인사이트 / 계정 상태
- 제목, 점수, 카드, 입력 폼 크기 확대
- 기존 기능 ID 유지
- 인사이트 발행 주기 20분에 1회 유지

## 검증
```bash
npm run validate:phase294
npm run phase294:final
```
