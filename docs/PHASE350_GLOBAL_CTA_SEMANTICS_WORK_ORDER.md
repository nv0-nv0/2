# PHASE350 전역 CTA 의미 통일 작업지시서

## 현재 판단
phase349까지 메인/진단 엔진은 통합되었지만, 일부 보조 페이지와 인사이트/로그인/결제 진입점에 `무료 진단 시작`, `사이트 구조 진단` 같은 과거 CTA 표현이 남아 있었다. 고객 입장에서는 같은 진단 기능인지, 별도 페이지 이동인지, 단순 콘텐츠 링크인지 헷갈릴 수 있다.

## 이번 단계 목표
전역 공개 페이지에서 진단 CTA 의미를 `사이트 무료 진단 실행`으로 통일하고, 결과 생성 전후 행동은 `결과 저장하고 이어보기`로만 표현한다. 고객 포털은 저장/관리 목적의 후속 기능으로만 위치시킨다.

## 구현 범위
1. 공개 페이지 HTML/JS의 진단 CTA 문구 통일
2. 메인/진단 단일 엔진 계약 유지
3. 과거 CTA 표현 금지 게이트 추가
4. phase350 최종 명령 체계 통일
5. phase349 누적 게이트를 계승한 최종 릴리즈 게이트 구성

## 제외 범위
- 실제 운영 서버 배포
- 실제 결제사 웹훅 검증
- 실제 모바일 기기 수동 테스트

## 완료 기준
- `npm run phase350:final` 통과
- `npm run release:predeploy` 통과
- `npm run delivery:final` 통과
- `./RUN_ALL_TESTS.sh` 통과
- public HTML/JS에서 legacy CTA 표현 제거
