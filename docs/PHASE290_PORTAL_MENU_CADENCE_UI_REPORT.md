# PHASE290 Portal Menu / Cadence / UI Readability Report

## 문제
- 인사이트 발행 주기를 사용자가 20분에 1회로 명확히 지정했다.
- `/portal` 내 사이트 화면에서 상단 메뉴가 부족해 이동 동선이 약했다.
- 하단 카드와 동적 영역이 조잡하게 보이고, 숫자/본문 크기와 배열이 일관되지 않았다.

## 조치
- 자동 인사이트 주기를 서버 기준 20분에 1회로 고정했다.
- API/UI 표시 문구를 `20분에 1회 발행`으로 통일했다.
- `/portal` 상단에 가로 메뉴를 추가했다.
- 기존 좌측 메뉴 의존도를 제거하고 상단 메뉴 중심으로 정리했다.
- 대시보드 카드를 12컬럼 기준으로 재배열했다.
- 점수, 인포그래픽 숫자, 빠른 실행, 다음 행동, 사이트 현황, 최신 인사이트, 계정 상태의 글자 크기와 간격을 재조정했다.
- 모바일 2열/1열 전환 규칙을 보강했다.

## 검증
```bash
npm run validate:phase290
npm run phase290:final
```
