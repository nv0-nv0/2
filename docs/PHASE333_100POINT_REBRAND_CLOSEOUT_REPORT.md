# PHASE333 100점 리브랜딩 클로즈아웃 리포트

## 목적
phase332 이후에도 실서버에서 확인된 구버전 고객 노출 요소, 중복 푸터, 검증되지 않은 마케팅 수치, 내부 운영용 API 노출 가능성을 기준으로 재검토하고 상용 고객 화면 기준으로 정리했다.

## 핵심 변경
- 모든 public HTML을 `data-veridion-rebrand="v333"` 기준으로 재마킹했다.
- 홈 화면의 검증되지 않은 지표와 가상 후기성 문구를 제거하고 진단 구성·리포트 구조 중심으로 변경했다.
- 실제 요금 구조와 홈 요금 카드의 불일치를 정리했다.
- 고객 포털 기본 플랜 표시를 실제 로그인 상태 기반 안내로 변경했다.
- 고객 UI에서 20분 발행, 자동 발행, 내부 운영성 cadence 문구가 나오지 않도록 `정기 업데이트`로 통일했다.
- `/api/public/trustops-*`, `/api/public/automation-workqueue`, `/api/public/live-verification-checklist` 계열 내부 운영성 엔드포인트는 public에서 404로 숨기도록 차단했다.
- 기존 테스트와 검증 스크립트를 phase333 기준으로 갱신했다.

## 품질 기준
- public 고객 화면에 구버전 메뉴명, 내부 운영 용어, 검증되지 않은 지표가 없어야 한다.
- 모든 public 페이지에는 단일 main, 단일 footer, v333 리브랜딩 마커가 있어야 한다.
- 기능 연결 ID는 유지해 진단, 로그인, 결제, 고객 포털 흐름이 깨지지 않아야 한다.

## 최종 게이트
`npm run phase333:final`
