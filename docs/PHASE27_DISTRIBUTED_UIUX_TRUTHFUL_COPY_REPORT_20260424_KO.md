# Phase27 분산형 UI/UX 및 문구 정합성 개선 보고서

## 목적
메인 페이지에 기능·요금·수익 모델·사례를 과도하게 몰아넣지 않고, 각 전용 페이지가 자기 역할을 수행하도록 재정리했습니다. 또한 검증되지 않은 수치형 문구를 제거하고 실제 서비스 제공 범위 중심으로 문구를 교체했습니다.

## 반영 사항
- 메인 페이지를 `진단 시작`, `문서 초안 생성`, `상품 보기` 중심의 관문 구조로 축소했습니다.
- `47+`, `98.7%`, `10,000+`, `24시간` 등 확인되지 않은 실적·정확도 표현을 제거했습니다.
- 주요 기능 설명은 접힘/펼침 구조로 정리해 첫 화면 부담을 줄였습니다.
- 상품·요금 페이지는 전용 페이지로 유지하고, 1회성 상품·정기 관리·인증/B2B를 섹션별로 분리했습니다.
- 상품 상세는 접힘/펼침 영역에 배치해 간결함과 상세함을 동시에 유지했습니다.
- 문서 초안 생성 입력값은 예시 기본값 없이 빈 상태로 유지했습니다.
- 결과/문서창은 밝은 배경, 고대비 텍스트, 명확한 테두리 기준을 유지했습니다.
