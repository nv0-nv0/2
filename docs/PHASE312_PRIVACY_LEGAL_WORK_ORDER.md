# PHASE312 개인정보·법률 리스크 제로 게이트 작업 지시서

## 원칙
- 법률 리스크를 수학적으로 0으로 보장할 수는 없으므로, 운영 게이트는 `미확정 정보가 있으면 배포·결제·회원 기능을 막는 방식`으로 설계한다.
- 개인정보 보호법, 개인정보 보호법 시행령, 개인정보의 안전성 확보조치 기준, 개인정보 처리방침 작성지침을 기준으로 개인정보 최소수집·가명처리·보존기간 제한·유출 대응 체계를 구현한다.
- 본 산출물은 법률 자문이 아니며, 정식 결제 오픈 전 변호사/개인정보 전문가 최종 검토가 필요하다.

## 레드팀 결론
- 원문 IP 저장 제거: 감사/세션/관리자 세션은 `ipHash`만 저장한다.
- 결제 원문 저장 차단: 카드번호·CVC·계좌 원문 저장 금지.
- 소스 내 개인 주소·대표자명·사업자번호 하드코딩 제거: 상용 배포 시 환경변수 주입.
- 위탁사·연락처·사업자 정보가 미확정이면 상용 게이트 실패 처리.
- 개인정보 유출 대응은 72시간 신고 검토 타임라인과 즉시 통지 체계를 운영 문서화한다.
