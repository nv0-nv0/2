# VERIDION 시스템 제어면 운영 고도화

## 목적

시스템 제어면 v1.1은 엔진·에이전트·레이어·파이프라인의 구조 무결성뿐 아니라 운영 이벤트의 안전성, 의존성 전파, 중복 억제, 최신성 표시를 함께 관리합니다.

## 핵심 보강

- 플랫폼 기반 레이어에 `system-control-plane-engine`을 단일 책임 엔진으로 배정했습니다.
- 12개 핵심 파이프라인에 책임 레이어, 선행 의존성, stale 기준, runbook 식별자를 연결했습니다.
- 파이프라인 의존성은 순환 없는 DAG인지 검증합니다.
- 상위 파이프라인이 차단되면 의존 파이프라인도 차단 상태로 전파됩니다.
- 운영 메모에 환경변수 시크릿, Bearer 토큰, `nv0_` 계열 토큰, URL 사용자 비밀번호가 포함돼도 저장 전에 마스킹합니다.
- correlation ID 또는 동일 이벤트 fingerprint가 짧은 시간 안에 반복되면 중복 저장을 억제합니다.
- 이벤트 저장 순서가 뒤섞여도 생성 시각 기준으로 최신 이벤트를 정렬합니다.
- 공개 API는 운영 메시지, 내부 파일 경로, 에이전트 상세를 노출하지 않습니다.

## 운영 원칙

1. P0 파이프라인의 `blocked` 상태를 가장 먼저 해소합니다.
2. 복구 후에는 동일 파이프라인에 `recovered` 또는 `healthy` 이벤트를 기록합니다.
3. 민감정보는 메모에 입력하지 않습니다. 실수로 입력해도 마스킹되지만 원문 입력 자체를 피합니다.
4. correlation ID는 배포 ID, 사고 ID처럼 재사용 가능한 운영 추적 키로 사용합니다.
5. `/api/admin/system-control-plane/audit`에서 구조 무결성 점수가 100인지 릴리즈 전 확인합니다.
