# PHASE59 전체 사이트 문구 자연화 수정 보고서

## 작업 범위
메인뿐 아니라 공개 사이트 전반의 화면 문구, 버튼, 안내문, 상태 메시지를 하나의 이용 흐름에 맞게 다시 정리했습니다.

## 수정 기준
- 고객이 실제로 이해하는 말로 작성
- 내부 용어보다 행동 중심 문장 우선
- 무료 진단 → 내 사이트 저장 → 상품 비교 → 결제 → 산출물 확인 흐름 일관화
- CTA 자동 발행 게시판의 역할 유지
- 코드 내부 값은 유지하고 화면 표기만 자연스럽게 변경

## 주요 수정 화면
- 메인: 문제 제기, 무료 진단, 저장, 상품 선택, FAQ 문구 전면 자연화
- 무료 진단: 결과 확인 후 다음 행동이 바로 보이도록 문장 정리
- 상품·요금: Pro/Fix/Auto 중심의 내부 표기를 상세 리포트/수정 문구안/정기 점검 중심으로 보완
- 결제: 선택 상품 표기를 한글화하면서 내부 결제 값은 유지
- 내 사이트 관리: 저장, 재진단, 주문, 산출물 흐름을 고객 관점으로 정리
- CTA 게시판: 자동 발행의 목적을 재방문·전환 장치로 명확화
- 문서 초안/가이드/정책 페이지: 어색한 직역식 표현을 자연 문장으로 정리

## 확인 사항
- 문서 초안 미리보기 id 오염 복구: docPreview 유지
- 정기 점검 상품 결제 코드: 화면 표기는 한글, 내부 값은 Auto 유지
- 영어 섹션 라벨 주요 항목 한글화
