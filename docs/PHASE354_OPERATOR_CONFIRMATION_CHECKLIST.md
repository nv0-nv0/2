# PHASE354 운영자 확인 체크리스트

## 배포 전 사용자 확인 필요

공개 HTML 화면, 서버 기본 설정, 배포 환경변수 템플릿에는 사업자 고지를 위한 운영 주체 정보가 포함되어 있습니다. 전자상거래 및 고객 고지 목적일 수 있으므로 자동 삭제하지 않았습니다.

배포 전 운영자가 아래 항목을 직접 확인해야 합니다.

- [ ] 현재 공개 화면에 표시되는 상호, 대표자명, 사업자등록번호, 통신판매 관련 정보가 실제 운영 주체와 일치한다.
- [ ] 공개 화면에 표시되는 사업장 주소의 공개 범위가 운영자의 의도와 법적 고지 범위에 맞다.
- [ ] 샘플 또는 이전 운영자 정보가 남아 있지 않다.
- [ ] `NV0_BUSINESS_*` 환경변수와 공개 정적 HTML의 고지 정보가 서로 일치한다.
- [ ] 정보 변경 시 정적 HTML, 서버 환경변수, 배포 템플릿을 함께 갱신한다.

## 적용 판단

- 자동 수정: 하지 않음
- 사유: 사업자 공개 정보는 삭제 시 법적·운영상 고지가 누락될 수 있음
- 배포 판정 영향: 운영자 확인 전까지 조건부 배포
