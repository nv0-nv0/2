# Phase19 낮음~중하 난이도 상용화 작업지시서

## 목표
NV0 Veridion의 현재 서비스 모델(웹사이트 법적·규제 리스크 진단 및 자동화)을 기준으로 구현·운영 난이도 낮음~중하 범위의 수익화 상품을 실제 판매 흐름에 연결한다.

## 제외 범위
- 변호사 1:1 매칭, 보험 연계, 자격증, 데이터 판매, 공공기관 전용, 해외 GDPR/CCPA 정밀 대응, 침투 테스트, NFT 인증은 운영·법적 책임 부담이 커서 이번 단계에서 제외한다.

## 구현 내용
1. `/api/public/products` 상품 카탈로그 API 추가
2. `/solutions` 수익 모델/상품 구조 페이지 추가
3. `/plans`를 상품·요금 중심으로 개편
4. `/checkout`에서 1회성 상품과 구독 상품을 모두 선택 가능하도록 확장
5. `/documents`에 템플릿 팩·업종별 가이드 구매 CTA 추가
6. 상단 메뉴에 `수익 모델` 링크 추가
7. 기존 무료 진단 → 유료 상품 전환 흐름 유지

## 권장 판매 흐름
무료 진단 → 정밀 PDF 리포트 → 맞춤 수정 문구안 → Pro 구독 → Certified 또는 Auto 업셀.

## 운영 체크포인트
- 실제 결제 모드에서는 PortOne 환경변수와 콜백 URL을 확인한다.
- 정밀 PDF 파일 생성 기능은 현재 상품화 CTA와 주문 생성까지 연결되어 있으며, 실제 PDF 생성 자동화는 다음 단계에서 서버 렌더링 또는 HTML-to-PDF로 고도화한다.
- 인증 마크는 결제 후 운영자 승인 기반으로 시작하고, 자동 검증은 추후 확장한다.
