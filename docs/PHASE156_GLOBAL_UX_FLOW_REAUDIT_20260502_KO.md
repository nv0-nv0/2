# PHASE156 전역 진단 재검수 및 UX 문장 흐름 정리

## 처리 범위
- 공개 페이지 전체 흐름: 홈 → 무료 진단 → 결과 요약 → 요금제 → 신청/결제 → 내 사이트 관리 → 게시판/문서/가이드 연결
- 사업자 정보 페이지의 미완성 문구 제거 및 실제 노출값 정리
- 결제 페이지 문맥 정리 및 불필요한 “운영 예정”류 공개 문구 제거
- 가이드/진단 결과의 조사 오류와 어색한 표현 수정
- 로그인 상태 내비게이션의 로그인/로그아웃 표시 흐름 재확인
- 기존 검증 스크립트 기준을 새 문구 기준으로 갱신
- P156 전역 검증 스크립트 추가

## 주요 수정
1. `apps/public/business-info/index.html`
   - “운영값 미입력”, “확정 후 입력” 계열 문구 제거
   - 호스팅 제공자를 `Contabo GmbH`로 명확 표시
   - 통신판매 관련 고지는 공개 placeholder가 아니라 운영 공개 전 대조 기준으로 정리

2. `apps/public/checkout/index.html`, `apps/public/checkout/app.js`
   - 제목을 `서비스 신청 | NV0`로 간결화
   - 반복되는 문장 구조 정리
   - “운영 예정 / 갤럭시아 결제 흐름” 공개 문구 제거
   - 결제 진행 상태 문구를 자연스럽게 변경

3. `apps/public/guides/index.html`, `apps/public/veridion-demo/app.js`
   - `버튼와` → `버튼과` 조사 오류 수정
   - 무료 진단 상태 문구를 “확인 중” 흐름으로 정리

4. `server/index.mjs`
   - 사업자 정보 기본 호스팅 제공자 fallback 정리
   - 문서 초안 생성 시 빈 입력 fallback을 자연스러운 표현으로 변경
   - 상품 카탈로그 API에 `marketPosition`, `valuePackWorth`가 일관되게 노출되도록 보강
   - 결제 비활성 상태 안내를 고객지원 신청 흐름으로 자연스럽게 정리

5. 검증 스크립트
   - `scripts/validate-phase156-global-ux-flow.mjs` 추가
   - `package.json`에 `validate:phase156`, `phase156:final` 추가
   - 기존 P105/P108/P118/P132 검증 기준을 새 공개 문구 기준에 맞게 보정
