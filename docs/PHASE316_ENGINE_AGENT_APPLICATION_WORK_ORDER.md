# PHASE316 엔진·에이전트 전역 적용 작업지시서

## 목표

phase315 유료 서비스 레드팀 보강본을 기준으로 진단, 인사이트, 상품, 체크아웃, 결제, 산출물, 환불, 개인정보, 보안, 관리자, 배포 게이트 전체에 엔진·에이전트 적용 구조를 고정한다.

## 적용 원칙

1. 단순 명칭 선언이 아니라 실제 런타임 이벤트에 에이전트 게이트를 남긴다.
2. 유료 전환 흐름은 체크아웃 전 동의, 가격 서버 고정, 대상 사이트 확정, idempotency를 통과해야 한다.
3. 결제 완료, 산출물 다운로드, 환불 요청은 권한과 상태가 맞지 않으면 실패한다.
4. 인사이트는 20분 발행 주기, 깨진 문자 차단, 게시물 존재성을 통과해야 공개한다.
5. 진단은 법률 결론으로 표시하지 않고, 무료 상세 결과는 유료 전까지 잠금 상태로 유지한다.
6. 최종 배포는 phase316 게이트에서 엔진 수, 에이전트 수, 이벤트 정책, 라우트 삽입, 문서, 감사 JSON을 검증한다.
