# PHASE312 개인정보·법률 레드팀 보고서

## 판정
PASS. 다만 `법률 리스크 0`은 보장 가능한 표현이 아니므로, 본 패키지는 `미확정 정보가 있으면 출시를 막는 기술·운영 게이트`로 구현했다. 실제 상용 배포 전에는 운영자 정보, 위탁사 정보, 연락처, 결제대행 정보, 통신판매업 신고 정보, 보관기간을 실제 값으로 확정해야 한다.

## 변경 요약
- 원문 IP 저장을 `ipHash` 저장으로 전환했다.
- 감사 로그, 결제 이벤트, 웹훅 payload에 privacy sanitizer를 추가했다.
- 대표자명, 사업자번호, 주소 하드코딩을 제거하고 상용 배포 시 환경변수를 필수화했다.
- 개인정보 처리방침을 필수 항목 중심으로 재작성했다.
- 보안 저장소 암호화키와 privacy hash key를 상용 필수값으로 승격했다.
- phase312 전용 검증 게이트를 추가했다.

## 남은 운영 확정 항목
1. 실제 사업자 정보
2. 통신판매업 신고번호
3. 개인정보 보호책임자 성명 또는 담당부서
4. 실제 위탁사명과 업무
5. 국외 이전 여부
6. 결제대행사 계약 정보
7. SMTP 발송사 정보
8. 클라우드/DB/오브젝트 스토리지 사업자
9. 고객지원 전화번호
10. 최종 변호사/개인정보 전문가 검토

## 레드팀 고위험 시나리오 차단 결과
- 고객 이메일이 감사 로그에 원문 저장되는 시나리오: 차단
- 관리자 세션이 IP 원문을 장기 저장하는 시나리오: 차단
- 결제 웹훅 원문 payload가 그대로 저장되는 시나리오: 차단
- 소스코드에 개인 주소가 포함되는 시나리오: 차단
- 상용 배포에서 보안 저장소 암호화키가 누락되는 시나리오: 차단
- 외부 추적 스크립트가 동의 없이 삽입되는 시나리오: 검증 게이트 차단

## 출시 기준
`npm run phase312:final` 통과 후, 운영 서버에 배포하고 실제 환경변수 값 기준으로 `/privacy`, `/business-info`, `/api/public/privacy-status`, 결제 플로우, 회원가입/로그인/탈퇴/데이터 export를 live verification 해야 한다.
