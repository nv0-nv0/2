# PHASE56 100점 상용화 전면 재검수 작업 지시서

## 1. 목표
NV0 공개 서비스의 목적은 단순 안내 페이지가 아니라 `무료 진단 → 신뢰 리스크 확인 → CTA 게시판 유입 → 상품 비교 → 결제 → 회원 포털 재방문`으로 이어지는 상용 전환 구조를 만드는 것이다. 이번 단계의 목표 점수는 내부 게이트 기준 100점이며, 사용자가 지적한 표기·구성 혼선, CTA 자동발행 누락 인식, 회원 편의 기능 부재를 P0로 처리한다.

## 2. P0 요구사항
1. 공개 화면 표기를 NV0 중심으로 통일한다.
2. CTA 게시판 자동발행 기능을 제거하지 않고 공개 게시판과 관리자 발행 관리에서 모두 보이게 한다.
3. 무료 진단 실행 시 CTA 게시글이 자동 생성되고, 게시판에서 `자동발행` 여부를 확인할 수 있게 한다.
4. 로그인 회원은 본인 사이트를 저장, 조회, 재진단, 상품 비교, 저장 해제할 수 있어야 한다.
5. 로그인 상태에서 무료 진단을 실행하면 해당 사이트가 계정에 자동 연결되어야 한다.
6. 고객 포털은 주문/산출물만 보여주는 화면이 아니라 `내 사이트 관리` 중심으로 재구성한다.
7. 기존 결제·환불·산출물 접근 권한과 보안 흐름을 훼손하지 않는다.

## 3. 구현 범위
- 서버 데이터 모델: `customerSiteLinks` 추가
- 공개 API: `/api/public/account/sites` GET/POST, `/api/public/account/sites/:siteId` DELETE 추가
- 무료 진단 API: 로그인 세션 감지 후 사이트 자동 저장, CTA 자동발행 ID 응답
- 고객 계정 API: 저장 사이트 목록을 계정 요약과 내보내기 데이터에 포함
- 공개 포털: 사이트 저장 폼, 저장 사이트 카드, 재진단/상품 보기/저장 해제 액션 추가
- 공개 게시판: `CTA 자동발행 게시판`으로 표기 개선, 자동발행 필터와 CTA 목적 설명 추가
- 릴리스 마커: `commercial-final-member-sites`

## 4. 완료 기준
- 서버 문법 검사 통과
- `test-all`: 88/88 통과
- `audit:global`: 100점
- `final:100`: 100점
- CTA 자동발행 공개 노출 확인
- 회원 사이트 저장 API가 비로그인 요청을 차단하고 로그인 회원 전용으로 동작

## 5. 운영 주의
실결제키, 포트원 웹훅, SMTP, Cloudflare 캐시/룰, 사업자 고지 최종값은 운영 서버 환경값이 필요하다. 이 패키지는 코드와 정적 UX 완성본이며, 실서버 외부 연동값 검증은 배포 환경에서 별도 수행해야 한다.
