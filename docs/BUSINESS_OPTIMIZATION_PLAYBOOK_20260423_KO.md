# Veridion 사업화 최적화 플레이북

## 1. 최적 구조
제품은 기능이 아니라 아래 구조로 판다.

1. 무료 진단
2. Basic 결제
3. 문서 생성
4. Pro 업셀(재스캔/알림/히스토리)
5. CTA 자동발행으로 신규 유입 확보

즉, **진단 → 문서 → 유지 → 업셀 → 자동유입** 구조가 최적이다.

---

## 2. 요금제

### Free
- 요약 진단
- 일부 가이드 열람
- CTA 진입

### Basic
- 상세 진단
- 문서 4종 생성
- PDF 리포트

### Pro
- Basic 전체
- 재스캔
- 법령 변경 알림
- 위험도 히스토리

Auto는 외부 연동/자동수정 안정화 후 2차 공개

---

## 3. 전환 퍼널

### 퍼널 1: 무료 진단 퍼널
- 유입
- URL 입력
- 위험도/과태료/상위 항목 노출
- 잠금된 상세 결과 노출
- Basic 결제로 전환

### 퍼널 2: 문서 퍼널
- 정책 문서 초안 생성
- 다운로드 전 결제 유도
- 결제 후 문서팩 제공

### 퍼널 3: 유지 퍼널
- 재스캔
- 알림
- 위험도 변화 시 재방문 유도
- Pro 업셀

---

## 4. CTA 자동발행 운영 원칙

CTA 자동발행은 유지하되 **콘텐츠 사업**으로 키우지 않는다.

### 유지할 것
- 무료 진단 CTA 글
- 법령 변경 요약 글
- 규제 키워드 가이드 글

### 하지 말 것
- 댓글/커뮤니티
- 수동 큐레이션 남발
- 지나친 카테고리 확장

### 목적
- SEO 유입
- 진단 시작 수 증가
- 문서 생성 전환 보조

---

## 5. 문서팩 판매 구조

### 기본 문서팩
- 개인정보처리방침
- 이용약관
- 환불/배송/교환 정책
- 필수 고지 문구

### 업종별 팩
- 자사몰 기본 팩
- 스마트스토어 팩
- 건기식 팩
- 병원 광고 팩
- 화장품 팩

### 판매 원칙
- 수동 커스터마이징 최소화
- 변수 입력형 템플릿 위주
- 문서 생성 결과를 바로 다운로드 가능하게

---

## 6. KPI

### 유입
- 무료 진단 시작 수
- 진단 완료율
- CTA 클릭률

### 수익
- Free → Basic 전환율
- Basic → Pro 업셀율
- ARPU

### 유지
- 재스캔 사용률
- 알림 열람률
- 해지율

### 운영
- 수동 처리 건수
- 자동 처리율
- 실패 작업 수

---

## 7. 최종 사업 판단

1인 운영 기준에서 가장 돈이 되는 구조는,
**복잡한 기능 확대보다 진단 정확도 + 문서 즉시성 + CTA 자동유입 + 재스캔 유지율**을 올리는 것이다.
