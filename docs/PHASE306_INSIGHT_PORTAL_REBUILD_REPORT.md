# PHASE306 인사이트/내 사이트 재구성 작업 지시서 및 납품 보고서

## 1. 작업 기준

- 대상 공개 사이트: `https://www.nv0.kr/board`, `https://www.nv0.kr/portal`
- 대상 패키지: `VERIDION_phase305_integrity_closeout_delivery(1).zip`
- 핵심 요구: 인사이트 페이지 정상 렌더링, 20분에 1회 자동발행, 내 사이트 페이지 깨진 도형/겹침 제거, 불필요 파일 정리, 전체 검증 후 납품

## 2. 발견 문제

### 인사이트 페이지

- 정적 HTML 기준으로 게시글 목록 영역이 비어 있고 `최신 인사이트를 불러오고 있습니다.` 상태에 의존하고 있었다.
- API 또는 JS 로딩이 지연될 경우 사용자는 게시판이 고장난 것으로 인식할 수 있었다.
- 자동발행 엔진은 존재했지만, 프런트엔드 실패 시 대체 게시글을 렌더링하는 안전 장치가 약했다.
- 일부 발행 문구가 `20분마다`와 `20분에 1회`로 혼재될 수 있어 운영 문구를 통일해야 했다.

### 내 사이트 페이지

- 장식용 특수기호와 아이콘 문자가 본문에 섞여 일부 환경에서 깨진 도형처럼 보일 수 있었다.
- 상단 메뉴, 히어로, 카드 그리드, 빠른 실행, 다음 행동 카드가 누적 CSS와 충돌할 가능성이 있었다.
- 정적 HTML에 오래된 날짜 샘플이 노출되어 실제 운영 화면처럼 보일 경우 신뢰도가 떨어질 수 있었다.
- 카드 폭, 버튼 높이, 모바일 재배열 기준이 최종 운영 페이지 기준으로 충분히 고정되어 있지 않았다.

## 3. 즉시 적용 작업

### 서버/자동발행 엔진

- `server/core/product-agent-suite.mjs`
  - 인사이트 엔진 버전을 PHASE306 기준으로 갱신했다.
  - 공개 금지/깨짐 가능 특수문자 필터를 확장했다.
  - 20분 발행 문구를 `20분에 1회 발행` 기준으로 통일했다.
  - 중복 발행·저품질 발행·잘못된 토큰이 공개 게시판으로 올라가지 않도록 품질 게이트를 보강했다.

### 인사이트 페이지

- `apps/public/board/index.html`
  - JS/API 지연 시에도 정적 기본 인사이트가 먼저 표시되도록 폴백 게시글을 삽입했다.
  - 빈 화면과 무한 로딩처럼 보이는 구조를 제거했다.
- `apps/public/board/app.js`
  - API 실패, 데이터 없음, 지연 상태에서 폴백 게시글과 활동 로그를 렌더링하도록 재작성했다.
  - 체크 아이콘 등 깨질 수 있는 기호를 일반 한글 텍스트로 교체했다.

### 내 사이트 페이지

- `apps/public/portal/index.html`
  - 깨진 도형처럼 보일 수 있는 장식 기호를 모두 일반 텍스트로 교체했다.
  - 오래된 정적 날짜를 `최근 진단 대기`, `20분 주기 자동 확인`, `계정에서 확인` 형태로 변경했다.
  - 상단 메뉴, 계정 영역, 대시보드 구조의 클래스 연결을 정리했다.
  - 기능 연결 ID는 유지하여 기존 JS 기능이 끊기지 않게 했다.
- `apps/public/portal/app.js`
  - 동적 렌더링 시에도 깨질 수 있는 아이콘/기호가 다시 삽입되지 않도록 정리했다.
  - 점수 막대 표시를 특수 블록 문자 대신 `n/10` 텍스트로 변경했다.
- `apps/public/portal/app.css`, `shared/portal-phase283-dashboard.css`
  - 1440px / 12컬럼 기준 대시보드 레이아웃을 강화했다.
  - 버튼, 입력폼, 카드, 상단 메뉴의 최소 높이와 반응형 재배열 기준을 보강했다.
  - 모바일에서 카드 겹침과 버튼 잘림이 발생하지 않도록 `min-width`, `overflow-wrap`, `word-break` 기준을 추가했다.

### 테스트/검증 스크립트

- `scripts/test-all.mjs`
  - 인사이트 주기 문구 기준을 `20분에 1회 발행`으로 갱신했다.
- `package.json`
  - 패키지 버전을 `1.0.0-commercial-phase306-insight-portal-rebuild`로 갱신했다.

## 4. 불필요/위험 요소 정리 기준

- 깨진 도형으로 보일 수 있는 공개 페이지 장식 기호를 제거했다.
- 테스트 실행 중 생성된 로컬 서버 프로세스는 종료했다.
- 기능 연결에 필요한 파일은 삭제하지 않았다. 이 패키지는 다중 검증 스크립트와 과거 단계 감사 문서가 운영 인수인계 자료 역할을 하므로, 무리하게 삭제하지 않고 공개 페이지 품질에 직접 영향을 주는 잔여 깨짐 요소를 우선 제거했다.
