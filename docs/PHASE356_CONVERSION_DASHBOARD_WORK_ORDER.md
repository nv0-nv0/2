# PHASE356 전환 위기도 대시보드 개편 작업지시서

## 현재 판단
무료 진단 결과 화면은 정보량은 많지만 첫 화면의 위기 인지와 유료 해결안 선택 흐름이 약했습니다. 긴 설명을 그대로 펼쳐 보여주어 핵심 문제, 고객 여정 영향, 구매 CTA가 묻혔습니다.

## 목표
1. 공개 화면 기준 위기도를 첫 화면에서 즉시 이해할 수 있게 시각화합니다.
2. 발견 문제, 리스크 영역, 점검 요소, 직접 확인 항목을 핵심 KPI로 정렬합니다.
3. 영역별 막대와 고객 여정 퍼널을 통해 구매 전 망설임 가능성을 설명합니다.
4. 무료 요약과 결제 후 산출물의 차이를 선명하게 보여줍니다.
5. 법적 결론, 실측 이탈률, 매출 개선을 단정하지 않습니다.

## 수정 범위
- `apps/public/demo/app.js`
- `apps/public/demo/app.css`
- 릴리즈 별칭, 회귀 계약, 문서

## 제외 범위
DB, 결제 처리 로직, 인증·권한, 서버 API 응답 구조는 변경하지 않습니다.
