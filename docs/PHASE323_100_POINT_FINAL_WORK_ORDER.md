# PHASE323 100점 최종 수정·개선·강화 작업지시서

## 목표
phase322 재진단에서 감점으로 남았던 실서버 검증 절차, 모바일/브라우저 UI 회귀, 운영 환경값 계약, 장시간 통합 게이트 안정성, 최종 인수 증적을 모두 패키지 내부 hard gate로 고정한다.

## 적용 범위
- 패키지 내부 점수판: 20개 영역 × 5점 = 100점
- release:predeploy / delivery:final 기준선 phase323으로 상향
- 통합 게이트를 단일 긴 shell chain에서 순차 실행 runner로 전환
- 반응형/깨진 도형/레거시 CSS 재유입 계약 추가
- 운영 환경값·사업자정보·개인정보·결제·스토리지 계약 추가
- TrustOps 100점 공개/관리자 API 추가
- 엔진 50개, 에이전트 108개, 이벤트 정책 19개로 확장

## 차단 기준
- 패키지 내부 100점 미달
- 실패 영역 1개 이상
- phase323 최종 스크립트 누락
- release:predeploy가 phase323을 바라보지 않음
- 실서버 확인 항목이 문서/JSON/API에서 분리되지 않음
- 런타임 찌꺼기 또는 시크릿 후보 포함
