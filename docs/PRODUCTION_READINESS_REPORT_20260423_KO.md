# 프로덕션 준비도 보고서 (2026-04-23)

## 1. 총평
현재 패키지는 **로컬 클린룸 검증본**으로는 탄탄하다. 공개 앱, 관리자 앱, 서버 세션, CSRF, 백업/복원, 운영 리포트, 스모크, E2E, 세션 지속성, 환경검증까지 로컬 기준 근거가 있다.

다만 실제 프로덕션 납품 판정은 아직 보수적으로 유지해야 한다. Contabo 실서버, Coolify, Cloudflare, 실도메인, PostgreSQL, 실결제, 실스캔 엔진은 이 세션에서 직접 검증되지 않았다.

## 2. 상태 표
| 영역 | 상태 | 근거 |
|---|---|---|
| Public App | 실제 확인 완료 | 로컬 렌더/E2E 통과 |
| Admin App | 실제 확인 완료 | 세션/CSRF/E2E 통과 |
| API App | 실제 확인 완료 | 헬스체크/주요 API 통과 |
| 로컬 운영 자동화 | 실제 확인 완료 | smoke, verify:prod, validate:env, ops:report |
| 배포 문서/입력값 | 실제 확인 완료 | runbook, matrix, worksheet, cutover docs |
| Contabo 실서버 | 동작 확인 필요 | 미접속 |
| Coolify 실배포 | 동작 확인 필요 | 미배포 |
| Cloudflare 실규칙 | 동작 확인 필요 | 미적용 |
| PostgreSQL 영속 전환 | 검증 미완료 | 현재 runtime JSON 저장 |
| 실결제 | 확인되지 않음 | 외부 스펙 미제공 |
| 실스캔 엔진 | 확인되지 않음 | 외부 스펙 미제공 |

## 3. 이미 닫힌 위험
- 공개 홈 관리자 링크 노출
- `/admin` 직접 허브 노출
- 관리자 저장소 토큰 의존
- 관리자 쓰기 요청 CSRF 미보호
- 업로드 기본 검증 부재
- 백업 생성만 있고 복원 경로 부재
- 서버 재시작 시 세션 소실
- 배포 전 환경값 누락 탐지 부재

## 4. 아직 남은 위험
- Cloudflare Full(strict) / Origin CA 실제 미검증
- Coolify healthcheck와 실제 컨테이너 상태 연동 미검증
- 운영 도메인 쿠키/SameSite/Proxy 환경 실제 미검증
- 영속 DB 전환 전까지 동시성/복구 범위 제한
- 외부 결제/스캔 엔진 실패 시나리오 미검증

## 5. 권장 납품 판정
- 즉시 검토 가능 여부: 가능
- 즉시 시연 가능 여부: 가능(로컬 기준)
- 즉시 인수 검토 가능 여부: 가능
- 즉시 프로덕션 납품 가능 여부: 불가
- 즉시 운영 가능 여부: 불가

## 6. 프로덕션 납품 최소 조건
1. Contabo 서버 생성 및 SSH 보안 초기화
2. Coolify 설치 및 앱 배포
3. Cloudflare DNS/SSL/Origin CA/Cache Rule 적용
4. 실도메인 `nv0.kr` 기준 `verify:prod` 수행
5. PostgreSQL 연결 또는 현재 파일 저장 유지 여부 최종 판정
6. 백업/복구 리허설 1회
7. 컷오버 후 24시간 모니터링
