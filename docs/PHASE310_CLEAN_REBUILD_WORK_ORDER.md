# PHASE310 Clean Rebuild Work Order

## 목표
포털과 인사이트 화면의 누적 패치, 중복 CSS, 깨진 도형 후보, 오래된 정적 문구를 제거하고 운영 화면 기준으로 새로 구성한다.

## 작업 범위
- `/portal` 내 사이트 관리 화면 클린 리빌드
- `/board` 인사이트 화면 클린 리빌드
- 단일 디자인 시스템 `shared/veridion-clean-v310.css` 적용
- 레거시 UI 주입 로직이 v310 화면에 간섭하지 않도록 서버 렌더링 보정
- 20분 인사이트 자동 발행 API 계약 유지
- 오래된 phase 보고서, 이전 보정 CSS, 불필요 아티팩트 정리
- 최종 검증 게이트 `phase310:final` 통과

## 완료 기준
- 상단 공백, 세로 잘림, 깨진 도형 후보 없음
- 포털과 인사이트가 같은 디자인 시스템으로 동작
- CSS/JS 누적 충돌 제거
- 테스트, 링크, 보안, 배포 번들, 시크릿 위생 검사 통과
