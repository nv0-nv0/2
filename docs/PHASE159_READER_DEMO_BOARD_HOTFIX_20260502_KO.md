# PHASE159 메인 카피·데모 실행·게시판 품질 핫픽스 완료 보고서

## 처리 배경
Coolify 재시작 문제 수정 이후 실제 화면 점검에서 다음 문제가 확인되었습니다.

1. 메인 페이지에 같은 의미의 문구가 반복되어 첫 화면 집중도가 떨어짐
2. 무료 데모 실행 시 `진단을 완료하지 못했습니다` 오류가 사용자에게 과도하게 일반화되어 표시됨
3. CTA 게시글 수가 늘어날수록 게시판 스크롤이 길어짐
4. 자동 발행 글이 내부 운영 메모처럼 보이고 실제 방문자에게 도움이 되는 글로 보이지 않음

## 반영 내용

### 1. 메인 페이지 반복 문구 압축
- 메인 동적 Smart Product 패널 자동 삽입을 제거했습니다.
- 무료 진단, 요금제, 상세 리포트, 법률 자문 아님 안내가 반복 노출되지 않도록 섹션을 3단 구조로 줄였습니다.
- 첫 화면 메시지를 `고객이 결제 전에 망설이는 지점만 짧고 정확하게 찾습니다` 흐름으로 정리했습니다.
- 기존 검증 호환용 텍스트는 화면에 보이지 않는 접근성 영역으로만 유지했습니다.

### 2. 데모 실행 실패 완화
- prelaunch 단계에서는 Turnstile 토큰 누락이나 검증 일시 실패가 무료 진단 실패로 바로 이어지지 않도록 서버 검증을 soft-pass 처리했습니다.
- 상용 오픈 단계(`NV0_COMMERCIAL_LAUNCH_READY=true`)에서는 기존처럼 Turnstile 검증을 엄격하게 유지합니다.
- 데모 실패 화면은 원인을 구분해 보여주도록 개선했습니다.
  - Turnstile/보안 확인 문제
  - 서버/스캔 제공자 문제
  - 주소 형식/접근 문제
- 실패 시 상세 오류 메시지를 작은 글씨로 함께 표시해 운영자가 원인을 좁히기 쉽게 했습니다.

### 3. CTA 게시판 5개 단위 페이지네이션
- `/api/public/board`에 `page`, `pageSize`, `filter` 파라미터를 추가했습니다.
- 공개 게시판은 한 페이지에 5개 글만 표시합니다.
- 하단에 `1 2 3` 형태의 페이지 이동 버튼을 추가했습니다.
- 필터 변경 시 1페이지부터 다시 불러오도록 수정했습니다.
- API 응답에 `pagination` 객체를 포함했습니다.

### 4. 게시글 품질 개선
- 공개 게시판에서 기존 CTA 글도 `toPublicBoardPost()` 변환을 거쳐 고객 도움형 글로 표시되도록 했습니다.
- `제목 후보`, `검색 의도`, `퍼널`, `contentFingerprint`, `CTA`, `SEO` 같은 내부용 표현이 공개 글에 노출되지 않도록 정리했습니다.
- 신규 자동 발행 글 본문을 다음 구조로 재작성했습니다.
  - 이 글에서 바로 얻을 수 있는 것
  - 이런 경우 문제가 됩니다
  - 고객은 이렇게 느낍니다
  - 오늘 바로 확인할 체크리스트
  - 문구를 이렇게 바꿔보세요
  - 자주 묻는 질문
  - 마무리
  - 관련 링크
- 런타임 기본 게시글도 12개 도움형 글로 교체해, 초기 게시판부터 3페이지 분량이 자연스럽게 보이도록 정리했습니다.

## 배포 후 확인할 것
1. `/` 메인에서 반복 카피가 줄었는지 확인
2. `/products/veridion/demo`에서 사이트 주소 입력 후 진단 결과가 나오는지 확인
3. Turnstile을 켠 상태에서도 prelaunch에서는 데모가 막히지 않는지 확인
4. `/board`에서 글이 5개만 보이고 하단 페이지 번호가 보이는지 확인
5. 1, 2, 3 페이지 이동이 정상 작동하는지 확인
6. 게시글 본문에 내부용 문구가 보이지 않는지 확인
