# NV0 공개 화면 고객 중심 문구 수정 지시안

## 1. 수정 목표
- 메인 화면에서는 무료 문서 초안 생성 폼을 노출하지 않는다.
- 문서 초안 생성 기능은 `/documents` 메뉴 진입 후 사용하도록 동선을 분리한다.
- 공개 화면에 노출되는 내부 운영용 표현을 고객이 이해하기 쉬운 표현으로 바꾼다.
- CTA, KPI, 자동발행, 수익 모델, 운영 난이도, 포트원 등 내부·개발·마케팅 관리 용어는 고객용 표현으로 완화한다.

## 2. 적용 기준
| 분류 | 기존 표현 방향 | 고객 중심 변경 방향 |
|---|---|---|
| 메인 화면 | 문서 입력 폼 즉시 노출 | 진단/상품 확인 중심, 문서 초안은 전용 메뉴 이동 |
| 운영 문구 | 운영, 운영 난이도, 운영 효율 | 이용, 이용 난이도, 고객 신뢰/점검 편의 |
| 마케팅 내부 용어 | CTA, 전환, KPI, 수익 모델, 반복 매출 | 버튼, 신청률/확인율, 상품 구성, 정기 점검 |
| 자동화 과장 표현 | 자동수정, 자동발행 | 고객 확인 후 사용할 수정 후보, 정기 인사이트 제공 |
| 결제 개발 용어 | 포트원, SDK, 세션, 주문 생성 | 안전한 결제창, 결제 확인, 서비스 신청 |
| 상품 설명 | 판매/매출/업셀 중심 | 고객 상황별 필요 산출물과 이용 방식 중심 |

## 3. 파일별 처리 내역
| 파일 | 처리 내용 |
|---|---|
| `apps/public/home/index.html` | 메인 화면 무료 문서 초안 생성 폼 제거. `/documents` 진입 CTA로 변경. |
| `apps/public/home/app.js` | 메인에서 문서 입력 폼을 사용하지 않는 안내 주석 정리. |
| `apps/public/plans/index.html` | 상품·요금 화면의 운영/전환 중심 문구를 서비스 이용 중심 문구로 변경. |
| `apps/public/plans/app.js` | 카드 상세 영역의 `이용 방식`, `확인 가능한 효과` 기준 유지. 서비스 정보 상태 문구 개선. |
| `apps/public/solutions/index.html` | 수익 모델/상용화/반복 매출 문구 제거. 상품 구성 안내 페이지로 변경. |
| `apps/public/solutions/app.js` | 기존 링크 호환 안내 문구를 상품 구성 안내 기준으로 변경. |
| `apps/public/checkout/index.html` | 주문 중심 문구를 서비스 신청 중심 문구로 변경. |
| `apps/public/checkout/app.js` | 주문 생성, 결제 수단, 포트원 노출 표현을 고객용 결제 안내로 변경. 깨진 함수명 복구. |
| `apps/public/board/app.js` | CTA 게시판 느낌을 공개 사례/고객 안내 점검 사례로 변경. |
| `apps/public/terms/index.html` | 운영 지원/이벤트 로그 표현을 이용 지원/결제 확인 기록으로 완화. |
| `runtime/data/db.json` | 초기 게시글의 CTA/자동수정/운영 리스크 문구를 고객 안내 리스크 문구로 변경. |
| `runtime/data/db.seed.json` | 시드 데이터도 동일하게 변경. |
| `server/index.mjs` | API로 공개될 상품 설명, 산출물, 효과 지표, 게시글 생성 문구를 고객 중심으로 변경. |

## 4. 주요 변경 문구
| 기존 | 변경 |
|---|---|
| 무료 문서 초안 생성 | 문서 초안은 전용 페이지에서 작성하세요 |
| 운영 난이도 | 이용 난이도 |
| 결제 전환 | 부담 없는 이용/확인 |
| KPI | 확인 가능한 효과 |
| CTA 자동발행 | 정기 고객 안내 인사이트 |
| 자동수정 후보 | 고객 확인 후 사용할 수정 후보 |
| 수익 모델 | 상품 구성 |
| 반복 매출 | 정기 점검 |
| 포트원 결제 세션 | 결제 세션 또는 안전한 결제창 |
| 주문 생성 | 서비스 신청 정보 확인 |

## 5. 확인 결과
- `node --check apps/public/checkout/app.js` 통과
- `node --check apps/public/plans/app.js` 통과
- `node --check server/index.mjs` 통과
- 공개 화면 기준으로 `수익 모델`, `운영 난이도`, `자동수정`, `자동발행`, `CTA` 직접 노출 문구 제거 확인

## 6. 배포 후 확인 항목
- `/` 메인에서 문서 초안 입력 폼이 보이지 않는지 확인
- `/documents`에서 문서 초안 생성 기능이 정상 작동하는지 확인
- `/plans` 상품 카드 상세 열림/닫힘이 정상 작동하는지 확인
- `/checkout`에서 결제창 호출 및 결제 완료 확인 문구가 자연스러운지 확인
- `/board`에서 게시글 제목과 본문이 고객 안내 사례처럼 보이는지 확인
