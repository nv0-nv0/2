# NV0 Phase264 Functional Hardening Report

## 반영 요약
- 메인 페이지 무료 진단 버튼을 실제 `/products/veridion/demo` 이동 링크로 수정했습니다.
- 위험 진단 페이지의 고정 `nv0.kr` 입력창과 정적 데모 블록을 제거했습니다.
- 실제 진단 API와 연결되는 `targetUrl`/`scanBtn`/`demoResult` 세트를 페이지 최상단 영역으로 올렸고, 하나만 남겼습니다.
- 서비스 페이지의 해외 규정·쓸데없는 예시 문구를 제거하고 국내 온라인 사업자 전용 서비스로 재정리했습니다.
- 색상 팔레트를 청록/네이비 기반으로 교체하고 카드/CTA/입력창 대비를 강화했습니다.
- 인사이트 페이지의 정적 가짜 글을 제거하고 실제 `/api/public/board`와 연결되는 게시판 앵커만 남겼습니다.
- 로그인 페이지를 2열 2칸 카드 구조로 재배열했습니다.
- 로그인/회원가입/재설정 이메일 입력칸은 기본값 없이 빈칸으로 시작하며, URL email 파라미터 자동 노출은 없습니다.

## 추가 검증
- `validate:phase264` 스크립트를 추가해 이번 요청 사항을 자동 검사합니다.
