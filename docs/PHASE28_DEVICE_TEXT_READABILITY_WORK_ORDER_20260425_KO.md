# PHASE28 기기별 표기·자동 줄바꿈·글자 크기 최적화 지시안

## 목적
모바일, 태블릿, 데스크톱에서 긴 한글 문구·버튼·카드·표·문서 미리보기가 깨지지 않도록 표기 품질을 정리한다.

## 적용 범위
- `shared/base.css`
- `apps/public/home/app.css`
- `apps/public/plans/app.css`
- `apps/public/documents/app.css`

## 처리 항목
1. 한글 문장 줄바꿈 최적화
   - `word-break: keep-all` 적용
   - 긴 URL, 이메일, 영문 혼합 문자열은 `overflow-wrap: anywhere`로 화면 밖 이탈 방지

2. 제목·본문 가독성 개선
   - 제목에는 `text-wrap: balance` 적용
   - 본문에는 `text-wrap: pretty` 적용
   - 모바일 제목 크기와 줄간격 재조정

3. 버튼·메뉴 표기 안정화
   - 버튼과 메뉴의 `white-space: nowrap` 고정 해제
   - 모바일에서는 CTA와 메뉴가 한 줄에 억지로 눌리지 않도록 전체 폭 버튼 처리

4. 표·문서 미리보기 대응
   - 표는 가로 스크롤 컨테이너 유지
   - 셀 내부 한글 줄바꿈 개선
   - 문서 미리보기 `pre` 영역은 줄바꿈 유지와 긴 문자열 이탈 방지 병행

5. 홈 화면 최적화
   - 메인 헤드라인, 핵심 범위 카드, 안내 단계, 빠른 링크의 줄바꿈과 간격 보정
   - 680px 이하 화면에서 좌측 정렬로 모바일 읽기 흐름 개선

6. 상품·요금 화면 최적화
   - 탭 메뉴 모바일 2열/1열 반응형 처리
   - 상품 카드 가격·설명·버튼 깨짐 방지
   - 비교표 최소 폭을 줄여 모바일 스크롤 부담 완화

## 기대 결과
- 모바일에서 제목이 과도하게 작아지거나 어색하게 끊기는 문제 감소
- 긴 문구, 이메일, URL, 상품명, 버튼 문구가 화면 밖으로 밀리지 않음
- 데스크톱에서는 기존 시각 톤을 유지하면서 모바일 가독성 강화
