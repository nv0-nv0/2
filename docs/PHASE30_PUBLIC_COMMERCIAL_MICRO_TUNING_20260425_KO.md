# PHASE30 공개 화면 상용화 미세 튜닝 적용 내역

## 목적
고객이 보는 공개 화면에서 공급자 관점·내부 운영 관점·불필요한 난이도 표현을 숨기고, 모바일/태블릿/PC에서 문구가 가장 자연스럽게 보이도록 표기와 반응형 가독성을 보완했다.

## 반영 범위
- 요금제 카드 상세 문구의 `이용 안내`를 `확인 안내`로 전환
- 상품 비교 영역에서 내부 코드 노출을 서비스 분류명으로 전환
- 상품 상태 문구에서 추천 상품 코드 직접 노출 완화
- 서버 상품 카탈로그의 고객 노출 문구를 고객 중심 표현으로 재정리
- Auto 상품명을 `Auto 정기 케어`로 완화
- `관리 부담`, `고위험 표현`, `결제 완료 후 산출물` 등 고객에게 딱딱하게 보이는 문구를 자연스럽게 수정
- 공개 CSS 전역에 자동 줄바꿈, 긴 URL/이메일 방지, 모바일 버튼/메뉴 1열 정렬, 표 가로 스크롤 보정 추가
- 문서 초안은 참고용임을 명확히 안내하는 문구 유지

## 공개 화면에서 숨긴 표현
- 운영 난이도
- 이용 난이도
- 내부용 KPI/CTA 표현
- 수익 모델
- 관리 포인트
- 개발자식 결제/SDK 표현
- 중하/낮음 등 공급자 평가 배지

## 검증
- `npm run check:syntax` 통과
- `npm run check:pages` 통과
- `npm run check:links` 통과
- `npm run check:render-safety` 통과
- `node scripts/check-commercial-offers.mjs` 통과

## 비고
상용 배포 전 실제 결제 승인/취소/환불 시나리오와 운영 환경 변수는 배포 서버에서 별도로 확인해야 한다.
