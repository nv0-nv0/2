# PHASE29 공개 화면 내부성 문구 숨김 처리

## 처리 원칙
고객이 보는 공개 화면에서는 공급자·운영자 관점의 표현을 노출하지 않는다. 특히 요금제/상품 화면에서 고객이 불안하게 느낄 수 있는 난이도, KPI, CTA, 내부 운영, 자동 발행, 수익 모델, 관리 포인트류 문구를 제거하거나 고객이 얻는 가치 중심 문구로 바꾼다.

## 반영 항목
1. 상품·요금 비교표에서 `이용 난이도` 컬럼 제거
2. 상품 카드 상단의 `낮음`, `중하` 등 난이도 배지 제거
3. 난이도 배지를 `1회 이용`, `정기 점검`, `연간 인증`, `기업·대행사`처럼 고객이 이해하기 쉬운 서비스 유형 배지로 변경
4. `상세 구성과 이용 방식` 문구를 `상세 구성 보기`로 완화
5. `대상 고객`을 `추천 대상`으로 변경
6. `제공 산출물`을 `제공 내용`으로 변경
7. `확인 가능한 효과` 영역을 고객 가치 중심의 `기대할 수 있는 도움`으로 변경
8. 상품 API 응답에서 난이도 필드 노출 제거
9. 상품 API의 내부 지표형 `kpi` 항목을 고객 가치형 `benefits` 항목으로 변경
10. 솔루션 안내 페이지의 `이용 난이도` 표현 제거
11. 공개 화면 기준 `운영`, `내부`, `KPI`, `CTA`, `자동 발행`, `수익 모델`, `관리 포인트`, `포트원`, `SDK`, `모드` 문구 노출 여부 재검색
