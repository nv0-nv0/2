# PHASE237 시각 QA 체크리스트

## 삭제 확인
- [ ] HTML에서 이전 shared CSS 링크가 남아 있지 않다.
- [ ] `/apps/**/app.css`는 빈 은퇴 파일로만 남아 있다.
- [ ] `/shared`의 CSS는 `nv0-clean-slate-20260512.css` 하나뿐이다.

## 시인성 확인
- [ ] 헤더/본문/보조 텍스트 대비가 충분하다.
- [ ] CTA와 일반 버튼이 색상과 형태로 명확히 구분된다.
- [ ] 모바일 360px 폭에서 카드 겹침, 글자 깨짐, 가로 스크롤이 없다.
- [ ] 폼 입력창, 에러/주의/성공 상태가 색상만이 아니라 텍스트와 형태로도 구분된다.

## 페이지별 확인
- [ ] 홈: 무료 진단 시작 CTA가 첫 화면에서 보인다.
- [ ] 무료 진단: URL 입력창이 가장 눈에 띈다.
- [ ] 결과: 점수, 근거, 다음 행동이 분리되어 보인다.
- [ ] 요금: Free/Report/FixPack/Auto 차이가 즉시 이해된다.
- [ ] 결제: 금액, 결과물, 환불 안내, 동의 항목이 결제 전에 보인다.
- [ ] 관리자: KPI와 운영 액션이 명확하게 분리된다.
