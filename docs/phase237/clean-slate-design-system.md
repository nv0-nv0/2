# PHASE237 Clean Slate 디자인 시스템

## 핵심 원칙
- 기존 phase 누적 CSS, 응급 색상 보정, 페이지별 덮어쓰기 CSS를 기준 디자인에서 제외한다.
- 런타임 HTML은 `/shared/nv0-clean-slate-20260512.css` 하나만 로드한다.
- 페이지별 `app.css`는 의도적으로 비워 두어 새 공용 시스템이 유일한 시각 레이어가 되도록 한다.
- 글자색은 `#0B1220`, 본문은 `#172033`, 보조 텍스트는 `#667085`를 기본으로 사용한다.
- 주요 CTA는 `#245BFF`, 안전/완료는 Emerald, 주의는 Amber, 위험은 Rose로 통일한다.

## 페이지별 시각 전략
- 홈: 큰 히어로, 진단 흐름 카드, 가치 제안 CTA.
- 무료 진단: 입력 폼 중심, 확인 범위, 상태 메시지 명확화.
- 결과: 위험도 게이지, 우선순위 바, 자동/수동 확인 분리.
- 상품·요금: 4단계 카드, 추천 상품 강조, 가격 대비 결과물 명확화.
- 콘텐츠 보드: 좌측 필터, 중앙 콘텐츠, 우측 운영 상태.
- 문서 생성: 입력/미리보기 2분할.
- 내 사이트: 사이드바 + 대시보드 카드.
- 결제: 결제 정보와 주문 요약 분리, 동의/환불 고지 가시화.
- 관리자: KPI, 운영 액션, 로그 프리뷰 중심.
