# PHASE237 페이지 목적 맵

| 페이지 | 핵심 목적 | 시각 요소 | CTA |
|---|---|---|---|
| 홈 | 신뢰 진단 가치 즉시 이해 | 히어로, 흐름 카드, 신뢰 칩 | 무료 진단 시작 |
| 무료 진단 | URL 입력 유도 | 대형 입력 폼, 확인 범위 카드 | 진단 시작 |
| 진단 결과 | 문제 우선순위 이해 | 게이지, 바 차트, 확인 구분 카드 | 리포트/FixPack |
| 상품·요금 | 상품 선택 | 4단계 가격 카드, 추천 강조 | 결제/무료 진단 |
| 콘텐츠 보드 | 운영 글 탐색 | 필터, 게시글 카드, 활동 사이드바 | Auto 결제 |
| 문서 생성 | 산출물 생성 | 입력/미리보기 분리 | 초안 생성 |
| 내 사이트 | 계정 기반 관리 | 사이드바, KPI 카드, 다음 작업 | 사이트 등록 |
| 결제 | 구매 전 최종 확인 | 요약 카드, 동의 박스, 안내 스트립 | 결제하기 |
| 관리자 | 운영 상태 확인 | KPI, 액션 버튼, 로그 카드 | 운영 액션 |
