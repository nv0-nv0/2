# PHASE274 Customer Copy & Readability Report

## 목적
고객 화면에서 제작자·내부 운영자 관점의 문구를 제거하고, 고객이 실제로 궁금해하는 내용 중심으로 다시 구성했습니다.

## 반영 내용
- “정리했습니다”, “2열로 정리”, “정적 예시 제거”, “검수/납품”처럼 제작 과정이 드러나는 표현 제거
- 메인, 인사이트, 내 사이트, 요금 안내, 로그인, 결제, 상세 진단 화면의 고객 관점 문장 보정
- 무료 데모 표현을 고객 친화적인 “무료 진단”으로 통일
- 시인성 낮은 회색 계열을 더 진한 본문색으로 보정
- 제목, 본문, 카드, 버튼, 입력칸의 크기·간격·대비 재조정
- 기존 즉시 진단, 결과 확인, 내 사이트 이동, 인사이트 20분 발행 기능은 유지

## 검증
`npm run validate:phase274`에서 고객 화면 금지 문구, 허위 신뢰 문구, 대비/폰트/간격 보정 레이어, 핵심 기능 보존 여부를 확인합니다.
