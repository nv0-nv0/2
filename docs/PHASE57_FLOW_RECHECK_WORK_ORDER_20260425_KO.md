# PHASE57 구조·흐름 재검수 작업 지시서

목표: 첫 방문부터 무료 진단, 로그인, 내 사이트 저장, CTA 자동발행 게시판, 상품 비교, 결제, 산출물 확인까지 끊기지 않는 상용 흐름으로 재정비한다.

## 사용자 여정
1. 메인: 문제 인식과 URL 입력
2. 무료 진단: 위험도와 상위 리스크 확인
3. 내 사이트 관리: 로그인 회원 사이트 저장, 재진단, 상품 비교, 주문·산출물 확인
4. CTA 자동발행 게시판: 진단/운영 이슈를 공개 게시글로 전환하고 무료 진단으로 재유입
5. 상품·요금: 무료 결과 기반으로 Pro, FixPack, Auto 선택
6. 결제: 동의 확인 후 신청
7. 포털: 결제 산출물과 재점검 흐름 관리

## 수정 기준
- 공개 메뉴는 무료 진단, 내 사이트, CTA 게시판, 상품·요금 순서로 정렬한다.
- CTA 자동발행 게시판은 삭제하지 않고 핵심 전환 장치로 유지한다.
- 포털은 저장 사이트 중심으로 재진단, 상품 비교, Pro 신청 버튼을 제공한다.
- 무료 진단 결과는 상품 비교와 내 사이트 관리로 동시에 이어져야 한다.
- 모든 문구는 고객 행동 기준으로 정리한다.
