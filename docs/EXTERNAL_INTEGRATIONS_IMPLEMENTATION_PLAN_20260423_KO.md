# 외부 연동 구현 계획 (2026-04-23)

## 1. 결제 연동
상태: 확인되지 않음

### 필요한 입력
- 결제사명
- 서버용 secret key
- 클라이언트용 public key
- 성공/실패 리다이렉트 URL
- 웹훅 서명 검증 규칙

### 최소 구현 범위
- 결제 세션 생성 API
- 결제 성공/실패 콜백 처리
- 주문 상태 `pending -> paid` 전환
- 중복 웹훅 방지
- 감사로그 기록

## 2. 실스캔 엔진 연동
상태: 확인되지 않음

### 필요한 입력
- 스캔 API base URL
- 인증 방식
- timeout / retry 기준
- 동기/비동기 응답 구조
- 실패 코드 규칙

### 최소 구현 범위
- `/api/public/scan` 내부의 stub 교체
- 요청/응답 매핑 함수
- timeout 정책
- 외부 실패 시 사용자 메시지
- 감사로그 기록

## 3. 공통 원칙
- 외부 연동은 인터페이스 분리 후 주입
- 관리자 화면은 외부 연동 실패에도 진단 가능해야 함
- retry는 무한 금지
- 결제/스캔 모두 request id 추적 필요
