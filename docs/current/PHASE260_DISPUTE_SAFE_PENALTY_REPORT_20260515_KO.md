# PHASE260 오해·분쟁 소지 완화 패치 보고서

## 목적
PHASE259에서 추가한 과태료 강조 UI의 시각적 긴장감은 유지하되, 사용자가 실제 행정 판단이나 공식 법률 판단으로 오해할 수 있는 표현을 제거했습니다.

## 적용 내용
1. 강한 과태료 금액 표현을 `과태료 상한 후보(참고용)` 기준으로 변경했습니다.
2. 경고 배지는 `확정 안내 아님 · 검토 필요`로 변경했습니다.
3. 우측 패널 제목을 `과태료·행정조치 가능성 검토 필요`로 변경했습니다.
4. 설명 문구에 관할기관 판단, 적용 법령, 사실관계, 전문가 검토에 따라 실제 결과가 달라진다는 점을 명확히 표시했습니다.
5. 직접적인 부과 표현을 `○○원 범위 검토 가능성`으로 완화했습니다.
6. `법령 구분`을 `검토 구분`으로 변경해 공식 판정처럼 보이는 위험을 줄였습니다.
7. 유료 산출물 범위가 과장 보장처럼 보일 수 있는 표현을 제거했습니다.
8. 서버 응답에 `penaltyEstimateType: reference_upper_bound_candidate`, `legalConclusion: false`를 추가했습니다.
9. 화면에 `법률 자문 아님 · 참고용 자동진단` 배지를 추가했습니다.

## 유지한 요소
- 빨강/주황 계열의 강한 시각적 경고 효과
- 과태료 상한 후보 금액의 큰 숫자 표시
- 문제 합계, 리스크 영역, 점검 요소, 검토 구분 KPI
- 유료 리포트 전환 흐름

## 주의
이 화면은 법률 자문, 공식 판단, 행정처분 예고를 의미하지 않습니다. 실제 판단은 관할기관, 적용 법령, 사실관계, 전문가 검토에 따라 달라질 수 있습니다.
