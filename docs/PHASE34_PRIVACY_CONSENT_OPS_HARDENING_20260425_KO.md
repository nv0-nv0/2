# Phase 34 개인정보 최소수집·동의·운영 보강 적용 보고서

## 적용 목적
상용화 단계에서 불필요한 개인정보 입력을 요구하지 않도록 유지하면서, 결제·산출물 제공에 반드시 필요한 동의와 운영 안전장치를 보강했습니다.

## 주요 변경
1. 회원 공개 응답에서 name/company 필드 제거
2. 회원가입 데이터 최소수집 버전 phase34 반영
3. 결제 단계 필수 항목을 이메일, 상품, 필수 약관 동의로 한정
4. 결제 화면에 개인정보처리방침·이용약관·환불정책 필수 동의 추가
5. 서버 checkout-session에서 필수 동의 누락 시 400 차단
6. 주문 레코드에 필수 동의 이력 저장
7. 고객 데이터 export API 추가
8. 고객 계정 비활성화 API 추가
9. 보안 헤더 Origin-Agent-Cluster, X-Permitted-Cross-Domain-Policies 추가
10. 테스트 요청에서 불필요한 buyerName 제거

## 개인정보 최소수집 기준
- 회원가입 필수: 이메일, 비밀번호 해시, 개인정보 처리방침 동의 시각
- 결제 필수: 산출물 수신 이메일, 상품, 주문번호, 결제 식별자, 필수 동의 이력
- 기본 미수집: 이름, 회사명, 전화번호, 주소
- 문서 초안 입력: 사이트 공개 고지에 필요한 경우 이용자가 직접 입력한 항목만 사용
