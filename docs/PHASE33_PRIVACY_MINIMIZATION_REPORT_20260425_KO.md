# PHASE33 개인정보 최소수집 및 상용화 하드닝 완료 보고서

작성일: 2026-04-25

## 적용 목표

회원가입, 결제, 문서 생성 과정에서 서비스 제공에 반드시 필요한 정보만 수집하도록 수정했습니다.

## 변경 사항

1. 회원가입 필수 항목 축소
   - 제거: 이름, 회사명
   - 유지: 이메일, 비밀번호, 개인정보 처리방침 동의
   - 서버 저장 필드도 email/passwordHash/동의시각 중심으로 축소

2. 결제 신청 정보 최소화
   - 제거: 담당자 이름 입력
   - 유지: 결제 및 산출물 전달용 이메일
   - 로그인 상태에서는 계정 이메일 자동 사용
   - 전화번호, 주소는 결제 단계에서 요구하지 않음

3. 문서 초안 생성 정보 구분
   - 필수 성격: 상호, 대표자 또는 책임자명, 도메인, 고객지원 이메일
   - 선택 성격: 연락처, 주소
   - 화면 문구에 선택 입력 및 필요 시에만 입력 안내 추가

4. 개인정보처리방침 정비
   - 회원 계정 필수 처리 항목을 이메일, 비밀번호 해시, 동의 시각으로 명확화
   - 일반 결제 과정에서 이름, 전화번호, 주소를 요구하지 않는다고 명시
   - 최소수집 원칙 섹션 추가

5. 문서 생성 기본값 조정
   - collectsPersonalData 기본값 true → false
   - marketingOptIn 기본값 true → false
   - 문서 초안 내 필수 수집 항목 표현을 이름/연락처 중심에서 이메일/주문번호/결제식별자 중심으로 수정

6. 관리자 고객 목록 최소화
   - 고객 공개 객체에서 name/company 반환 제거
   - 고객 식별은 id/email/status/order count 중심으로 유지

## 개인정보 최소수집 기준

- 회원가입: 이메일, 비밀번호, 동의 시각만 필수
- 로그인: 이메일, 비밀번호만 사용
- 비밀번호 재설정: 이메일, 토큰, 새 비밀번호만 사용
- 결제: 이메일, 주문번호, 결제 식별자, 상품 코드만 사용
- 산출물 다운로드: 계정 세션 또는 주문 접근 토큰 사용
- 문서 초안: 이용자가 직접 입력한 공개 사업자 정보만 사용

## 검증 결과

- 소스 문법 검사: 통과 출력 확인
- 라우트 스모크: 22/22 통과 출력 확인
- 개인정보 금지 입력 grep: registerName/registerCompany/buyerName 미검출

## 주의

실제 PortOne 운영 결제사 설정에서 구매자명이나 휴대폰번호를 필수로 요구하도록 계약되어 있으면 결제사 콘솔 설정도 함께 최소수집 기준으로 조정해야 합니다.
