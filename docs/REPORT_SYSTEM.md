# VERIDION Executive Trust Report System

## 목적

VERIDION의 진단 결과는 단순 점수 화면이 아니라 온라인 사업자가 고객의 구매 전 신뢰 공백을 빠르게 이해하고, 상세 실행 리포트 구매 여부를 판단할 수 있는 전문 보고서 체계입니다.

무료 결과는 전체 유료 리포트의 약 25%를 공개합니다. 충분한 판단 가치는 제공하지만, 실제 수정에 필요한 근거 URL, 페이지 내 정확한 위치, 수정 전후 문구, 적용 순서, 재점검 기준은 상세 리포트에서 엽니다.

## 보고서 정보 구조

| 구간 | 무료 공개 | 상세 리포트 |
| --- | --- | --- |
| Document Control | 리포트 ID, 분류, 범위, 발행일 | 고객 기밀 보고서 분류 |
| Executive Decision | 위험 방향, 상대 강도, 경영진 판단 | 상세 판단 근거 |
| Trust Exposure Map | 상위 위험 영역 일부 | 전체 영역, URL, 요소별 근거 |
| Buyer Friction Path | 결제 전 마찰 지점 | 페이지별 사용자 흐름 근거 |
| Control Snapshot | 4개 통제 영역의 방향 | 세부 통제별 판정과 개선안 |
| Priority Register | 상위 조치 후보 일부 | 전체 우선순위, 난이도, 실행 순서 |
| Evidence Ledger | 잠금 | 페이지별 근거 URL과 확인 상태 |
| Fix Specification | 잠금 | 정확한 위치와 수정 전후 문구 |
| 14-Day Roadmap | 잠금 | 적용 순서와 작업 계획 |
| Recheck Protocol | 잠금 | 적용 후 재점검 체크리스트 |

## 윤리적 전환 원칙

- 실제 매출 손실이나 법률 위반을 자동 확정하지 않습니다.
- 위험 점수는 공개 화면에서 확인한 신뢰 공백의 상대 강도입니다.
- 로그인 이후 화면, 외부 결제창, 업종별 판단은 직접 확인 대상으로 분리합니다.
- 무료 화면에서도 판단 방향과 한계를 명확하게 표시합니다.
- 구매 CTA는 실행 가능한 상세 산출물의 가치를 설명하며 허위 긴급성을 사용하지 않습니다.

## 100점 전역 배점표

| 평가 영역 | 배점 |
| --- | ---: |
| 문서 통제와 기관 보고서 형식 | 10 |
| 경영진 의사결정 요약 | 10 |
| 신뢰 노출 지수와 산정 한계 | 8 |
| 무료 25%와 유료 75% 경계 | 10 |
| 리스크 시각화 품질 | 8 |
| 구매 여정 마찰 분석 | 8 |
| 통제 스냅샷 | 6 |
| 우선 조치 원장 | 8 |
| 유료 산출물의 구매 가치 | 12 |
| 유료 상세 리포트 렌더링 | 6 |
| 윤리적 전환 설계 | 6 |
| CSP·접근성·모바일 안전성 | 5 |
| 샘플 화면과 실제 렌더러 일치 | 2 |
| 문서화와 릴리즈 게이트 | 1 |
| **합계** | **100** |

`npm run test:report-excellence`는 위 배점표를 코드로 실행합니다. 100점 미만이면 릴리즈 게이트를 차단합니다.


## 진단 시작 화면 디자인 전역 배점

`npm run test:report-excellence`는 리포트 결과뿐 아니라 실제 활성 경로 `/products/veridion/demo`의 시작 화면도 함께 평가합니다. 입력 행동의 우선순위, 3초 이해 가능성, 무료 25%·상세 75% 공개 경계, 보조 정보 저소음 배치, 보고서형 미리보기, 접근성, 모바일, CSP, 활성 라우트 동기화를 합산하여 100점 미만이면 릴리즈를 차단합니다.
