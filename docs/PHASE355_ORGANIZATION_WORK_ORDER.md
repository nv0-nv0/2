# PHASE355 전체 정리·정렬 작업지시서

## 목표

기존 PHASE354의 동작과 회귀 자산을 보존하면서, 신규 작업자와 운영자가 실행·검증·배포 경로를 즉시 찾을 수 있도록 구조를 정렬한다.

## 안전 원칙

- DB 스키마, 결제 로직, 인증 구조, 고객 UI 흐름은 변경하지 않는다.
- 과거 PHASE 문서와 검증 스크립트는 이동·삭제하지 않는다.
- 최신 릴리즈 진입점을 PHASE355로 통일한다.
- 문서 탐색성과 롤백 정확성을 개선한다.

## 적용 범위

1. README 롤백 경로 교정
2. `npm run help`, `verify:quick`, `verify:release`, `runtime:clean`, `dev` 추가
3. package.json 스크립트 알파벳 정렬
4. 문서 인덱스, 현재 릴리즈 안내, 생성 보고서 안내, 배포 안내 추가
5. PHASE355 감사와 최종 게이트 추가
6. 과거 검증기의 PHASE355 전방 호환성 반영
